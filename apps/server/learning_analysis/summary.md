# Pico AI

系统记录学生的编程过程，由程序持续维护结构化画像；Agent 读取相关画像和过程数据，指导当前任务、总结阶段表现并选择下一步学习活动。活动结果继续进入画像，形成闭环。

## 1. 学习内容

- 每项能力定义稳定 ID、目标行为和评价规则。
- 每个活动固定版本，关联题目、初始代码、目标能力和评价规则。
- 可推荐活动记录目的、目标能力、先修、难度、时长和帮助方式。

## 2. 学生过程数据

- 记录活动版本、代码快照、运行及测试结果、学生回答、实际展示的提示和活动完成情况。
- 每条数据关联学生、活动版本、作答机会和来源；重复上传不重复处理。
- 未采集的数据标为缺失，不当作失败。

## 3. 结构化画像

- 程序按作答机会和活动评价规则生成能力观察，并更新画像。
- 画像保存各能力的尝试数、不同帮助条件下的结果、行为统计、定性评价、学习目标及证据来源。
- 能力结果与行为记录分开统计；学生自述目标与评价结论分开保存。

## 4. Agent 分析与输出

- Agent 输入包括当前任务及版本、学生代码、运行和测试、已展示提示、相关画像与证据、学习目标及可用活动。
- Agent 区分观察事实与解释，指导学生采取一个具体的下一步动作，并引用相关证据。
- Agent 生成学生阶段概况，包括当前表现、优势、需练习内容、未评估问题和计划；程序画像不由 LLM 修改。
- 学习计划从已发布活动中选择，说明目标、理由、帮助方式及预期表现。暂无合适活动时可考虑生成新playground。

## 5. 结果回流

- 记录活动展示、完成、提示、运行和测试结果；按新观察更新画像。
- 用活动后的表现检查计划效果，区分当前题完成与无提示表现。
- 用户得到：
  - 编程指导
  - 讲解扩展
  - 下一步学习计划
